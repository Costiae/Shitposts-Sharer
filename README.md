# Shitposts Sharer（搬屎机器人）

AstrBot 扩展：在主动读取群聊时识别"潜在的屎"（聊天记录合并转发、图片、B 站分享等），
分析其内容特征，比对各群的"吃屎偏好"，并把屎搬运到偏好最匹配、可信度最高的群。

> 状态：需求澄清阶段（尚未开始实现）。

## 名词约定

| 术语 | 含义 |
| --- | --- |
| 屎 | 一条被判定为有搬运价值的群聊内容（合并转发记录、图片、视频分享、离谱文本等） |
| 原生屎 | 在某个群里天然产生（而非从别群搬入）的屎，用于校准该群的偏好 |
| 群口味 / 偏好 | 该群对屎的偏好向量（类别、来源、离谱度等维度） |
| 可信度 | 由"有效原生屎样本量 + 偏移度"决定的口味置信分 |
| 搬入 / 搬出 / 进出 | 群在搬运拓扑中的角色：只收、只发、既收又发 |

## 计划中的结构

```
main.py          # Star 入口：事件监听、指令注册
metadata.yaml    # AstrBot 插件元数据
core/
  detector.py    # 屎检测（合并转发的证据 + 内容分类）
  profile.py     # 群口味与可信度模型
  router.py      # 搬运路由：挑选目标群
  store.py       # 持久化
```
